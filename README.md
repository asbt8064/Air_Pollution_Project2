Air Pollution Measurements in Durham County, North Carolina

Project Description

This project analyzes daily air pollution measurements in Durham County, North Carolina, from 2018 to April 2020.

The analysis focuses on three pollutants:

Carbon monoxide (CO)

Fine particulate matter (PM2.5)

Ozone (O3)

The project examines daily minimum and maximum concentrations, monthly trends, and 95% confidence intervals.

Data

The datasets include air quality measurements from 2018, 2019, and 2020.

Files

Zhang_Zijie_Project2.Rmd: R Markdown source code and analysis.

data/AQ_2018.csv: 2018 air quality data.

data/AQ_2019.csv: 2019 air quality data.

data/AQ_2020.csv: 2020 air quality data.

Word report: Final project report.

Reproducibility

The analysis was conducted using R and RStudio.

Required R packages:

tidyverse

lubridate

knitr

To reproduce the analysis, open the R Markdown file in RStudio and knit it to Word.
